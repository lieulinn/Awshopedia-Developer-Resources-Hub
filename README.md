# DEVHUB — Awshopedia Developer Resources Hub

DEVHUB adalah platform katalog *resources* dan *tools* pengembangan web yang dikurasi secara terstruktur. Proyek ini memamerkan antarmuka berbasis *dashboard/hub* yang ramah pengembang, performatik, dan responsif.

---

## Fitur Utama

- **Kategori Terstruktur**: Akses cepat ke kategori utama (HTML, CSS, JavaScript, React, Git, GitHub, API, UI Resources).
- **Pencarian Real-Time**: Fitur pencarian cepat dengan dukungan *keyboard shortcut* (Tekan tombol `/` untuk langsung mencari).
- **Sistem Bookmark (Favorites)**: Fitur menyimpan *resource* favorit yang persisten menggunakan `localStorage`.
- **Indikator Level**: Penanda tingkat kesulitan (Beginner, Intermediate, Advanced, All Levels).
- **Responstif & Dashboard UI**: Tata letak sidebar modern yang dapat menyesuaikan tampilan layar perangkat seluler.

---

## Teknologi yang Digunakan

- **HTML5**: Struktur portal semantik.
- **CSS3**: CSS Variables, Flexbox, CSS Grid, Fira Code font integration, dan styling tema gelap (Dark Theme).
- **JavaScript (ES6+)**: Filtering array dinamis, manipulasi DOM, event listener keyboard, dan interaksi LocalStorage.

---
